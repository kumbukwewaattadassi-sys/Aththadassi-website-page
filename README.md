# ශ්‍රී ලංකා ජාතික පාසල් වෙබ් අඩවිය (Next.js & TypeScript)

මෙය ශ්‍රී ලාංකික පාසල් සඳහාම සුවිශේෂී වූ නවීන, Curved UI Objects සහිත, Framer Motion animations සහ Article / News Management හැකියාව ඇති සම්පූර්ණ Next.js App Router Template එකකි.

## 🚀 තාක්ෂණික තොරතුරු (Tech Stack)
* **Framework:** Next.js 14 (App Router)
* **Language:** TypeScript (`.tsx`)
* **Styling:** Tailwind CSS (Curved components, custom Sri Lankan school color palettes - Maroon & Gold)
* **Icons:** Lucide React
* **Animations:** Framer Motion (Smooth entrance, floating badges, marquee notice tickers)

## 📁 විශේෂාංග (Features)
1. **Notice Ticker:** වැදගත් පාසල් නිවේදන scroll වන සජීවී ticker එක.
2. **Hero Section with Curved Badges:** නවීන curved shapes, floating awards සහ statistics.
3. **Principal's Message:** විදුහල්පතිතුමාගේ පණිවිඩය සහ අත්සන සහිත අංශය.
4. **Academics Section:** විද්‍යා, ගණිත, වාණිජ, කලා සහ තාක්ෂණවේදය විෂය ධාරා.
5. **Articles / News:** බ්ලොග් සහ පාසල් ප්‍රවෘත්ති කාණ්ඩ අනුව (Sports, Academic, Events).
6. **Clubs & Societies:** මාධ්‍ය ඒකකය, ක්‍රිකට්, තොරතුරු තාක්ෂණ සංගමය ආදී විස්තර.
7. **School Anthem Widget:** පාසල් ගීතය වාදනය කිරීමේ බොත්තම.
8. **Contact & Admissions Form:** විමසීම් පෝරමය සහ කාර්යාලීය තොරතුරු.

## 💻 ධාවනය කරන්නේ කෙසේද? (Quick Start)
```bash
# 1. Dependencies ස්ථාපනය කරගන්න
npm install

# 2. Development server එක Run කරන්න
npm run dev
```
බ්‍රවුසරයෙන් `http://localhost:3000` වෙත පිවිසෙන්න.
